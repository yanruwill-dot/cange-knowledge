关于这个知识库

灿哥说车

一个可搜索、可阅读、可整理的二手车业务知识空间。

内容从哪里来？

运营手册内容来自用户提供的《二手车门店标准化运营手册》电子版（原文件标注“周小勇”），按业务场景拆分，保留原文、表格与章节出处，供所有访客直接阅读。网站另有标明来源的原创入门示例。原文中的案例、数据、金融与制度条款反映资料自身表述，使用前应结合实际情况核验；不包含 ima 订阅库的未授权正文。

我的资料存在哪里？

收藏、已读、笔记与导入资料保存在当前设备的浏览器中，不会上传。换设备不会自动同步，清理浏览器数据可能丢失记录，请定期导出备份。

怎么更新全站资料？

个人资料可导入 TXT、Markdown 或本站 JSON 备份；导入只对当前浏览器可见。对所有访客发布的内容由网站维护者更新 GitHub 源文件后部署。
